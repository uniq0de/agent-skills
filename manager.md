## Skill Manager: Mandatory Guidelines for Coding Agents

**You MUST follow these rules before starting any task. No exceptions.**

---

### Rule 1: Identify Your Task Type First

Before writing a single line of code, classify your task:

| Task Type | Required Guideline |
|---|---|
| Creating or modifying an MCP tool | Read and follow `mcp-tools/SKILL.md` completely |
| Creating or modifying a Frontend application | Read and follow `frontend-design/SKILL.md` completely |

---

### Rule 2: Read the Relevant Guideline Before Acting

- Do NOT begin implementation until you have read the required guideline file in full.
- Do NOT skip sections of the guideline.
- If a guideline conflicts with a user instruction, flag the conflict before proceeding.

---

### Rule 3: Verify Compliance Before Delivering

Before presenting your work, self-check:
- [ ] Did I read the correct guideline for this task type?
- [ ] Does my implementation follow every principle in that guideline?
- [ ] Did I avoid every anti-pattern listed?
